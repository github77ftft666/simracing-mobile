# FRONTEND_CONTEXT

## PitLink PWA

- Клиент находится в `src/`, собран на React + Vite, рассчитан на горизонтальную ориентацию телефона.
- Управление использует `DeviceOrientationEvent`: `beta` — руль, `gamma` — газ/тормоз; для них применяются dead zone 5° и 7°. Базовое положение хранится отдельным флагом, поэтому допустимое значение `0°` не перезаписывает калибровку. Кнопка «Центр» также запрашивает разрешение iOS.
- Связь с ПК только локальная через WebSocket endpoint, сохранённый в `localStorage`; Windows Controller выдаёт защищённый `wss://` endpoint.
- В настройках есть сканирование `pitlink://pair` QR‑кода: endpoint и pairing‑token сохраняются. QR может передать локальную страницу установки CA; PWA сначала показывает её и не пытается обойти TLS‑проверку.
- PWA manifest и service worker находятся в `public/`.
